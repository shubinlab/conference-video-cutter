# Security and privacy

Conference recordings and transcripts can contain personal, confidential, or copyrighted material. The core can render them locally, but local rendering is not automatically permission to distribute media. Transcription may also use an explicitly selected cloud provider; that is a separate privacy decision.

- Verify that you are authorized to download, transcribe, cut, and publish the source media.
- Keep recordings, raw transcripts, signed URLs, cookies, API keys, and identifying metadata outside Git.
- Before cloud processing, show the provider, data sent, retention, estimated cost when known, and obtain explicit consent. Never treat a ChatGPT subscription as implicit API authorization.
- Use the bundled no-upload preflight before processing and keep its report with the private project, not in a public issue.
- Review generated filenames and `manifest.json` before sharing them.
- Do not publish manifests containing absolute local paths, private URLs, or provider tokens.
- Do not use this project for face recognition, biometric identification, or covert surveillance.
- Report a reproducible security issue privately to the repository maintainers rather than publishing credentials or private media in an issue.
